# Site OXGym Academia

Site estático (HTML + CSS + JS, sem build). Publicado no Railway a partir deste repositório.

- `index.html`: o site inteiro
- `assets/`: logos

## Para editar o WhatsApp
Em `index.html`, procure `var WHATSAPP = '';` e coloque o número com DDI + DDD, só números (ex.: `5535999998888`).
